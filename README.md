# 🛒 ShoppyGlobe – React E-commerce App

ShoppyGlobe is a basic e-commerce application built using **React + Vite**.

---

## 🚀 Features

- Product listing using API
- Product detail page
- Add to cart functionality
- Cart with quantity control
- Checkout with dummy form
- Order placement with redirect
- Redux state management
- Lazy loading & code splitting
- 404 page handling

---

## 🛠 Tech Stack

- React (Vite)
- React Router (CreateBrowserRouter)
- Redux Toolkit
- CSS

---

## 📦 Installation & Run


git clone <GITHUB_REPO_LINK>
cd shoppyglobe
npm install
npm run dev
